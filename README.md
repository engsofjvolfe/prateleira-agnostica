# prateleira

[![Licença do código](https://img.shields.io/badge/C%C3%B3digo-GPL--3.0-blue)](LICENSE)
[![Licença do conteúdo](https://img.shields.io/badge/Conte%C3%BAdo-CC_BY--NC--SA_4.0-blue)](LICENSE-CONTENT.txt)

Uma prateleira de peças que servem a qualquer projeto. Cada peça é uma pasta que faz uma
coisa só e funciona sozinha. Nenhuma peça sabe de um projeto: o que é de um projeto fica nas
pastas de dados dele e chega à peça pelo comando ou pela configuração.

## Como usar

A prateleira pode ficar em qualquer lugar: num lugar central, de onde vários projetos a
usam, ou dentro de um projeto. Para usar uma peça, leia o README dela: ele diz para que ela
serve, como funciona e como ligá-la num projeto.

Toda peça segue a [estrutura das peças](ESTRUTURA-DAS-PECAS.md), e todo README, o
[formato dos README](FORMATO-DOS-README.md). O que muda em cada versão fica no
[changelog](CHANGELOG.md).
