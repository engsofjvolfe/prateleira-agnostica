# O dicionário da central

O índice de tudo o que a [central](README.md) dá às peças, em ordem alfabética: cada nome,
em poucas palavras, e o link para onde ele se explica, no README da peça que o guarda.

| Nome | Em poucas palavras | Onde se explica |
| --- | --- | --- |
| `achados_da_lista` | lê a lista e testa os itens dela com o usuário da IA, com cada achado numa linha | [conferencia-de-protecao](conferencia-de-protecao/README.md#achados_da_lista) |
| `anotacao` | o arquivo em que um vigia anota o que guarda de uma sessão | [protocolo](protocolo/README.md#anotacao) |
| `ARQUIVO` | o tipo do caminho coberto que é um arquivo | [caminhos-cobertos](caminhos-cobertos/README.md#arquivo-pasta-atalho-onde_vai_aparecer-e-falta) |
| `ATALHO` | o tipo do caminho coberto que é um atalho | [caminhos-cobertos](caminhos-cobertos/README.md#arquivo-pasta-atalho-onde_vai_aparecer-e-falta) |
| `caminho` | o caminho inteiro de um arquivo que um uso nomeia | [protocolo](protocolo/README.md#caminho) |
| `caminho_escrito` | o caminho inteiro que um arquivo de dados escreve | [caminho-escrito](caminho-escrito/README.md#caminho_escrito) |
| `campos` | os nomes dos lugares marcados de um modelo | [modelo-de-texto](modelo-de-texto/README.md#campos) |
| `chamadas` | os usos de um lote do formulário | [protocolo](protocolo/README.md#chamadas) |
| `cobertos` | os caminhos que um caminho cobre | [caminhos-cobertos](caminhos-cobertos/README.md#cobertos) |
| `CODIFICACAO` | o jeito de gravar texto em que os arquivos se leem e se gravam | [leitura-de-texto](leitura-de-texto/README.md#codificacao) |
| `com_rodapes` | o texto que um documento deve ter, com os rodapés que ele leva | [rodape-de-documento](rodape-de-documento/README.md#com_rodapes) |
| `ComandoIlegivel` | o erro da linha do terminal que não se lê | [leitura-do-terminal](leitura-do-terminal/README.md#comandoilegivel) |
| `comandos_achados` | cada vez que uma linha do terminal roda um dos comandos procurados | [leitura-do-terminal](leitura-do-terminal/README.md#comandos_achados) |
| `compila` | prepara uma expressão regular | [expressao-regular](expressao-regular/README.md#compila) |
| `comum.schema.json` | os moldes que vários moldes usam | [conferencia-de-molde](conferencia-de-molde/README.md#os-moldes-comuns) |
| `conferido` | confere dados contra um molde | [conferencia-de-molde](conferencia-de-molde/README.md#conferido) |
| `configuracao_do_terminal` | lê a configuração do terminal | [leitura-do-terminal](leitura-do-terminal/README.md#configuracao_do_terminal) |
| `de_json` | lê um texto em JSON | [leitura-de-json](leitura-de-json/README.md#de_json) |
| `depois_do_comando` | as palavras que vêm depois de um comando | [leitura-do-terminal](leitura-do-terminal/README.md#depois_do_comando) |
| `desprotegidos` | testa, com o usuário da IA, se os caminhos que ficam fechados para a IA estão fechados | [conferencia-de-protecao](conferencia-de-protecao/README.md#desprotegidos) |
| `destino_do_atalho` | o caminho para onde um atalho leva | [caminhos-cobertos](caminhos-cobertos/README.md#destino_do_atalho) |
| `do_tipo` | diz se um valor é de um tipo do JSON | [tipo-de-json](tipo-de-json/README.md#do_tipo) |
| `eh_documento` | diz se um arquivo é um documento, pelo arquivo dos rodapés | [rodape-de-documento](rodape-de-documento/README.md#eh_documento) |
| `eh_redirecionamento` | diz se um sinal manda a saída para um arquivo ou lê de um | [leitura-do-terminal](leitura-do-terminal/README.md#eh_redirecionamento) |
| `ErroDeDados` | o erro do que impede o trabalho de uma peça | [erro-de-dados](erro-de-dados/README.md#errodedados) |
| `FALTA` | o tipo da pasta em que um caminho que ainda não existe vai aparecer, quando ela também não existe | [caminhos-cobertos](caminhos-cobertos/README.md#arquivo-pasta-atalho-onde_vai_aparecer-e-falta) |
| `le_conferido` | lê um arquivo JSON e confere contra o molde | [conferencia-de-molde](conferencia-de-molde/README.md#le_conferido) |
| `le_evento` | as partes de um formulário | [protocolo](protocolo/README.md#le_evento) |
| `le_fechados` | lê a lista: os arquivos e as pastas que ficam fechados para a IA, os nomes do usuário da IA e do usuário do programa, o pedido de administrador e o pedido de outro usuário | [conferencia-de-protecao](conferencia-de-protecao/README.md#le_fechados) |
| `le_json` | lê um arquivo JSON | [leitura-de-json](leitura-de-json/README.md#le_json) |
| `le_rodapes` | lê o arquivo dos rodapés de um projeto e confere | [rodape-de-documento](rodape-de-documento/README.md#le_rodapes) |
| `le_texto` | lê um arquivo de texto | [leitura-de-texto](leitura-de-texto/README.md#le_texto) |
| `leitura_do_terminal_temporaria` | a cópia temporária da leitura do terminal, com as listas de quem escreve num arquivo ou roda código | [leitura-do-terminal-temporaria](leitura-do-terminal-temporaria/README.md) |
| `ler` | lê a folha do protocolo | [protocolo](protocolo/README.md#ler) |
| `lidos` | as partes e as palavras de cada comando de uma linha do terminal | [leitura-do-terminal](leitura-do-terminal/README.md#lidos) |
| `lugar_real` | o lugar do disco em que um caminho fica, com a pasta dele no lugar real | [caminhos-cobertos](caminhos-cobertos/README.md#lugar_real) |
| `NAO_PASSOU` | o comando que acabou com o código de saída 1 | [resultado-de-comando](resultado-de-comando/README.md#passou-nao_passou-e-quebrou) |
| `no_repositorio` | diz se uma pasta fica num repositório git | [repositorio-git](repositorio-git/README.md#no_repositorio) |
| `ONDE_VAI_APARECER` | o tipo da pasta em que um caminho que ainda não existe vai aparecer | [caminhos-cobertos](caminhos-cobertos/README.md#arquivo-pasta-atalho-onde_vai_aparecer-e-falta) |
| `opcao_bate` | diz se uma opção aparece numa palavra | [leitura-do-terminal](leitura-do-terminal/README.md#opcao_bate) |
| `PASSOU` | o comando que acabou com o código de saída 0 | [resultado-de-comando](resultado-de-comando/README.md#passou-nao_passou-e-quebrou) |
| `PASTA` | o tipo do caminho coberto que é uma pasta, com tudo o que está dentro dela | [caminhos-cobertos](caminhos-cobertos/README.md#arquivo-pasta-atalho-onde_vai_aparecer-e-falta) |
| `pedido_para` | o pedido de outro usuário da lista, com o nome de um usuário no lugar marcado | [conferencia-de-protecao](conferencia-de-protecao/README.md#pedido_para) |
| `posicoes_de_comando` | as posições das palavras que rodam como comando | [leitura-do-terminal](leitura-do-terminal/README.md#posicoes_de_comando) |
| `preenche` | troca cada lugar marcado de um modelo pelo valor dele | [modelo-de-texto](modelo-de-texto/README.md#preenche) |
| `problemas` | os rodapés de um documento que estão fora do dia | [rodape-de-documento](rodape-de-documento/README.md#problemas) |
| `protocolo_temporario` | a cópia temporária do protocolo, com a mensagem da pessoa, o momento de depois de um uso e o aviso | [protocolo-temporario](protocolo-temporario/README.md) |
| `prova` | prova que o teste de uma peça pega os defeitos dela | [copias-estragadas](copias-estragadas/README.md#prova) |
| `QUEBRAS_COMO_ESTAO` | o que se diz, ao abrir um arquivo, para as quebras de linha ficarem como estão | [leitura-de-texto](leitura-de-texto/README.md#quebras_como_estao) |
| `QUEBROU` | o comando que acabou com outro código de saída | [resultado-de-comando](resultado-de-comando/README.md#passou-nao_passou-e-quebrou) |
| `repetidos` | acha os valores repetidos de uma lista | [repetidos](repetidos/README.md#repetidos) |
| `resposta` | o que um vigia responde, por um modelo da folha | [protocolo](protocolo/README.md#resposta) |
| `resultado` | roda um comando e diz como ele acabou | [resultado-de-comando](resultado-de-comando/README.md#resultado) |
| `roda.py` | roda uma peça com a central à mão | [roda](roda/README.md) |
| `rodapes_montados` | os rodapés de um documento, montados para ele | [rodape-de-documento](rodape-de-documento/README.md#rodapes_montados) |
| `separa` | separa o texto de um documento dos rodapés que ele tem | [rodape-de-documento](rodape-de-documento/README.md#separa) |
| os sinais do terminal | cada sinal do terminal, com nome | [leitura-do-terminal](leitura-do-terminal/README.md#os-sinais) |
| `texto_do_comando` | roda um comando e entrega, como texto, o que ele escreveu | [texto-de-comando](texto-de-comando/README.md#texto_do_comando) |
| `textos_de` | cada texto de dentro de um valor JSON | [protocolo](protocolo/README.md#textos_de) |
| `TIPOS` | os nomes dos tipos do JSON | [tipo-de-json](tipo-de-json/README.md#tipos) |
